The repository may contain source code, Python notebooks, assembly programs, command references, PDFs, and supporting files.

## Suggested organization for future additions

Keep each lab subject organized using these categories when applicable:

- `Code/` — source code and runnable programs
- `Notes/` — explanations, reports, and practical notes
- `Questions/` — lab tasks and question sheets
- `Resources/` — datasets, diagrams, and supporting files

Do not move existing files solely to match this suggestion without checking their links and dependencies.
