## Suggested convention for future files

- Keep one subject in one clearly named folder.
- Prefer descriptive filenames, for example `deadlock-notes.pdf` or `8086-instruction-set.pdf`.
- Separate lecture notes, solved problems, and reference materials when the collection grows.
