# CSE 3-2 Academic Resource Hub

A student-maintained academic repository for **B.Sc. in Computer Science & Engineering (CSE), University of Rajshahi**.

Course materials, lecture notes, lab code, practical resources, assignments, and previous examination questions are collected here for semester study and revision.

| Directory | Purpose |

| [`ru_std/`](ru_std/) | Subject-wise course materials, books, slides, notes, lab resources, and questions |

| [`lab-previous-questions/`](lab-previous-questions/) | Previous lab question papers and combined collections |

## How to Navigate

1. Start with `ru_std/` for regular course materials.
2. Open `LAB/` for practical work and source code.
3. Use [lab previous questions](lab-previous-questions/) and [previous-year questions](previous-year-questions/) for exam practice.
4. Check `my/` for personal study collections.

## Naming Convention

New folders and files should use descriptive English names and preferably `lowercase-kebab-case`. Use official subject names or clear abbreviations (CN, DSP, MAL, OS, PPM). Keep notes, code, slides, and questions clearly organized.

Some legacy directory names remain unchanged to preserve existing links and file history. New additions should follow the convention above.

## Contributing

1. Place each resource in the correct subject directory.
2. Use descriptive filenames, including subject and year/session where known.
3. Update the relevant README when adding a new resource category.
4. Avoid committing IDE caches, temporary files, generated build output, and unnecessary installers.
5. Share only files you are permitted to distribute.

## Disclaimer

This is a student-maintained collection. Files may be incomplete, outdated, duplicated, or contain errors. Verify important academic information against the official course outline and instructor-provided materials.
